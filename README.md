Tic Tac Toe

A classic two-player Tic Tac Toe game. Players take turns marking a 3x3 grid with X and O, and the first to get three in a row (horizontal, vertical or diagonal) wins.

How to play
Player X goes first, then players alternate turns.
Click an empty square to place your mark.
Get three marks in a row to win. If all 9 squares fill up with no winner, it's a draw.
